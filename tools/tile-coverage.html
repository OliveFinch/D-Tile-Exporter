Tile coverage checker

Loads tiles straight from the CDN in your browser to answer two separate questions: where does the imagery stop, and how much of the declared rectangle is actually empty. The first needs a few hundred requests. The second needs a sample, not a full sweep.

Source
What to run

Edges walks in from each declared edge until it finds a line holding at least one tile — the same method discover uses, run from a browser as an independent check. A line that looks empty is retested four times as finely before it is believed, because evenly-spaced sampling steps straight over thin features and near an edge is where coverage is thinnest. Density is a uniform random sample of the box: 400 samples pins the fill rate to about ±5%, and scanning more changes that answer very little.
